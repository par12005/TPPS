============================

The TreeGenes Plant Phenotype Submission (TPPS) system has been updated to support submissions that are compliant with the MIAPPE (Minimum Information About a Plant Phenotyping Experiment) standard. This document outlines the necessary steps and considerations for preparing and submitting MIAPPE-compliant data through TPPS. This documentation assumes that the reader is already familiar with the `MIAPPE`_ standard and its minimum requirements.

Investigation
-------------

Investigations in MIAPPE correspond to TGDRxxxx studies in TPPS.
